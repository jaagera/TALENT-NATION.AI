TOPIC: WHAT IS CODE AND WHAT IS PROGRAMMING LANGUAGE?

> Code is the written form of instructions for a computer.(a set of instructions written in a programming language that tells a computer what to do.)

> And a programming language is the system you use to write those instructions.(a system of rules and symbols that allows humans to write instructions that computers can execute.)

# Language	        Designed For
Python	            General purpose, readability, AI, data science
JavaScript	        Web development (running in browsers)
Java	            Enterprise applications, Android apps
C	                System programming, operating systems
C++	                Game development, performance-critical applications
Go	                Cloud infrastructure, high-performance servers
Rust	            Systems programming, memory safety

# Each language has its own:

* Syntax — the rules for writing code
* Ecosystem — libraries and tools available
* Strengths — what it's good at
* Community — who uses it and what they build with it
