TOPIC: WHAT IS PROGRAMMING?

> Programming is the process of giving a computer instructions for solving a problem.

THE IDEA AIM/GOAL
* Computer — the machine that executes instructions.
* Program — a set of instructions that tells the computer what to do.
* Data — the information a program works with.

> NOTE: A computer doesn't decide what you want. It executes instructions that have been provided to it.

* Programming involves two related activities:

1. Problem solving — You first determine: What needs to happen?
2. Implementation — You then express those instructions using a programming language: How do I tell the computer to do it?

> NOTE : Learn to look at a problem and ask, "What exact instructions would a computer need to solve this?"
