> What Is Python?
Python is a high-level, general-purpose programming language. >>> is a language we use to give instructions to computers.

> Why Python?
* Its readable 
* Reduces uncessary complexity
* Python has a large community
* Has a large ecosystem

> Python is like a language and a toolbox combined.
